# AI 생존 지수 - 맞춤형 생존 전략 플래너

AI 시대에 당신의 직무가 AI에게 대체될 위험도를 진단하고, 맞춤형 생존 전략을 제공하는 웹 애플리케이션입니다.

## 🎯 주요 기능

### 1. AI 생존 지수 진단 (STEP 1: 진단)
- 30개의 정교한 질문을 통해 업무 스타일 분석
- 4가지 차원 평가: 패턴성, 창의성, 공감력, 데이터 의존도
- 5분 이내 완료 가능한 간편한 설문

### 2. 진단 결과 시각화 (STEP 2: 분석)
- AI 대체 지수 (0-100%) 표시
- 레이더 차트로 방어 지도 시각화
- 위험 영역과 안전 영역 분석
- 개인화된 요약 코멘트 제공

### 3. 맞춤형 액션 플랜 (STEP 3: 처방)
- 진단 결과 기반 자동 생성
- 3단계 전략: 위험 제거 → 약점 보완 → 전략 수립
- 모듈식 시스템으로 각 사용자에게 다른 플랜 제공
- 구체적인 행동 과제 제시

### 4. 생존 노트 & 체크리스트 (STEP 4: 훈련)
- 과제별 체크리스트로 진행 상황 추적
- 생존 노트로 학습 내용 기록
- 진행률 시각화
- 필터링 기능 (전체/미완료/완료)

## 🚀 기술 스택

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks + Local Storage
- **Visualization**: Custom SVG Radar Chart

## 💡 핵심 특징

1. **AI API 불필요**: 정교한 로직 기반으로 맞춤형 전략 생성
2. **완전한 프라이버시**: 모든 데이터는 브라우저에만 저장
3. **실시간 개인화**: 진단 결과에 따라 완전히 다른 액션 플랜 제공
4. **실천 중심**: 단순 정보 제공이 아닌 실행 가능한 과제 제시

## 🎨 사용자 플로우

1. **홈페이지** → 앱 소개 및 시작
2. **설문 조사** → 30개 질문에 답변 (1-5점)
3. **진단 결과** → AI 대체 지수 및 레이더 차트 확인

## 📊 진단 로직

### 4가지 차원
1. **패턴성**: 반복적이고 정형화된 업무 (↑ 위험)
2. **창의성**: 새로운 아이디어와 혁신 (↑ 안전)
3. **공감력**: 인간관계와 감정 이해 (↑ 안전)
4. **데이터 의존도**: 수치 기반 의사결정 (↑ 위험)

### AI 대체 지수 계산
```
대체 지수 = (위험 점수 × 50%) + (안전 점수 역산 × 50%)
위험 점수 = (패턴성 + 데이터 의존도) / 2
안전 점수 = (창의성 + 공감력) / 2
```

## 🛠️ 액션 플랜 시스템

### 모듈 선택 조건
- 각 모듈은 특정 차원의 점수 범위에 따라 활성화
- 예: 패턴성 ≥ 3.5 → "반복 업무 자동화" 모듈 활성화
- 다중 모듈 조합으로 개인화된 플랜 생성

### 3단계 전략
1. **위험 제거 (Risk)**: AI가 대체할 수 있는 영역 방어
2. **약점 보완 (Weakness)**: 부족한 역량 개발
3. **전략 수립 (Strategy)**: 강점 활용 및 AI 협업 방법
